---
name: ct-learn-skill
description: Preserve verified learning from the current work as memory and, when useful, a managed Skill
---

Review the current session and this optional focus: $ARGUMENTS

1. Load any existing Skill that could cover the learning.
2. Recall relevant Mnemosyne memories.
3. Identify only verified, non-obvious, reusable learning from the current work.
4. Store one concise Mnemosyne memory when the lesson is durable.
5. When the lesson is a repeatable procedure, update an existing managed
   `ct-*` Skill or create one using the Claptrap format and length rules.
6. Prefer a project Skill unless the procedure is genuinely cross-project.
7. Never modify a Skill unless it is inside a Claptrap managed/archive
   subfolder, its immediate directory starts with `ct-`, and its metadata
   contains `managed-by: ct-gardener`.
8. A valid result is memory only or nothing worth retaining.

Report what was loaded, recalled, stored, created, or changed. Do not expose
private memory contents unnecessarily.
